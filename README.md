# 🌍 Global Flood & Rainfall Intelligence

AI-powered real-time rainfall monitoring and flood risk prediction system.

🔗 **Live App:**  
https://global-flood-rainfall-intelligence-mwgbjvev3pzbigshnauiao.streamlit.app/

---

## 📌 Overview

This project provides real-time rainfall analysis and flood risk prediction using weather data and AI-based risk scoring. It helps identify vulnerable zones and supports early flood preparedness.

---

## 🚀 Features

✔ Real-time rainfall monitoring  
✔ AI-based flood risk scoring  
✔ City search & dashboard  
✔ Rainfall trend visualization  
✔ Flood vulnerability map  
✔ Global heavy rainfall monitoring  
✔ Safety precautions guidance  

---

## 🛰 How It Works

1. Retrieves live weather forecast data  
2. Analyzes rainfall intensity & trends  
3. Calculates flood risk score  
4. Visualizes risk zones on interactive maps  
5. Displays global rainfall alerts
